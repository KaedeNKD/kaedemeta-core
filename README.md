# KaedeMeta Core

High-concurrency structured metadata and multimodal context extraction API built for modern AI Agents and automated workflows.

## Overview
KaedeMeta Core provides low-latency JSON normalization for publicly accessible web resources, enabling LLM agents and data pipelines to retrieve clean, structured metadata without heavy browser overhead.

## Core Capabilities
- **Zero-State Architecture:** Stateless RESTful & MCP-compatible endpoints.
- **High Concurrency:** Built with a high-performance native C++ core and lightweight gateway.
- **Standardized Schema:** Unified JSON output for seamless integration into LangGraph, n8n, and custom AI agents.
